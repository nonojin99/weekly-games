## 0. 한 줄
빈 화단에 씨앗이 떨어진다. 같은 식물 3개를 끌어다 합치면 한 단계 큰 식물이 되고, 큰 식물일수록 금화를 많이 낸다.
금화로 화단을 넓히고 물뿌리개를 키우다 정체되면 **계절을 넘겨**(환생) 이슬을 얻고, 다음 계절은 더 빨리 자란다.

**검증된 뼈대** = 머지 퍼즐(Merge Dragons/Merge Mansion 류 3→1 합성) × 인크리멘탈 환생 루프.
**감성 스킨** = 사계절이 바뀌는 정원 + 식물 도감. 누적이 "정원 풍경"으로 보인다.

## 1. 데이터 근거 (design-principles 6장)
- 1호 광맥 탐사대: 세이브 9명, **전원 다른 날 재방문**, 마지막 저장 10/01 — "내 것이 자란다" 구조가 작동. 성공 요인: 방치만으로 진행 + 보이는 누적(장비·투기장)
- 2호 종족 룰렛 디펜스: 세이브 7명, 재방문 3명(0.43), 마지막 09/29 — 긴 런·높은 난이도가 재방문을 깎음
- 결론: 3호는 1호 쪽 구조(방치 가능·짧은 판단 주기)로 돌아가되, 조작축을 **드래그 합성**으로 완전히 바꾼다

## 3. 3층 설계
- **층1 조작 (초)** — ① 드래그로 같은 식물 3개 합성(3→1; 5개 한 번에 합치면 2개 = 보너스) ② 물뿌리개 탭: 쿨다운 2초, 즉시 씨앗 1개. 벌칙 없음. 방치 시 자동 씨앗 주기 6초(물뿌리개 업그레이드로 ×0.92/단, 최대 20단 ≈ 1.1초)
- **층2 구매 판단 (분)** — 금화 소비처 3종: **화단 확장**(12→30칸, 60·1.8^k), **물뿌리개**(12·1.3^n, 20단 상한), **씨앗 등급**(600·10^n: 떨어지는 씨앗의 시작 티어 ↑). 판단: 칸이 꽉 차면 합성·판매로 공간을 만들지, 확장을 살지. 티어가 높을수록 칸당 효율 ×3.3이라 **합성은 늘 이득이지만 2개씩 남는 "짝 없는 식물"이 칸을 먹는다** → 확장 가치가 생긴다
- **층3 메타 (판 사이)** — **계절 넘기기**(환생): 누적 금화 ≥ T=400,000 에서 가능, 이슬 = ⌊√(누적/T)⌋, 영구 배율 `1 + 0.2·이슬` 이 **금화와 씨앗 속도 양쪽**에 적용(합성 체인을 타고 복리 → 2회차 가속이 체감됨). 리셋: 화단·업그레이드·금화. 유지: 이슬·도감·계절 수. 누적 화면 = **도감**(식물 티어별 첫 발견 기록) + **정원 전경**(계절이 넘어갈 때마다 배경·울타리·연못 같은 장식이 하나씩 추가)

자문: 메타 0 신규가 진행 가능한가 → 예(방치만으로 25분 내 첫 환생). 메타 다 찍으면 조작이 무의미한가 → 아니오(배율은 속도일 뿐, 합성은 항상 손으로 해야 함).

## 4. 경제 수식 (sim 상수 그대로)
```
티어 L 식물 금화/초 = 0.05 · 3.3^(L−1)        (3→1 합성이라 칸당 가치 1.1배/티어 → 합성은 "공간" 때문에 이득)
자동 씨앗 주기       = 6 · 0.92^water (s), water ≤ 20
탭                   = 2초 쿨다운 1개
화단 확장 비용       = 60 · 1.8^k (k = 0..17, 12→30칸)
물뿌리개 비용        = 12 · 1.3^n
씨앗 등급 비용       = 600, 6000, 60000, 600000 (티어 2~5 시작)
환생                 = cum ≥ 400,000 → 이슬 ⌊√(cum/T)⌋, 배율 1 + 0.2·이슬 (금화·씨앗 속도)
```

## 5. 첫 3분 (design-principles 4장)
- 0초: 화단 12칸, 씨앗 2개 이미 놓여 있음, 물뿌리개 하나. 설명 한 문장: **"같은 식물 3개를 끌어다 합쳐 보세요"**
- 첫 합성(≈15초) → 금화가 똑똑 떨어지기 시작 + 도감 첫 칸 열림(토스트만, 화면 전환 없음)
- 첫 구매(물뿌리개 12금화, ≈30초) 뒤 상점 탭 노출. 계절·이슬·도감 탭은 **첫 티어4(≈1분) 뒤**에 노출
- 가입(닉네임+PIN)은 **3분 경과 또는 첫 화단 확장 직후** "정원을 남길까요?"로. 그전엔 localStorage
- 오프라인: 복귀 시 `lastSeen` 기준 정산 — 자동 씨앗은 빈 칸까지만, 금화는 당시 생산량 × 경과(50%, 8시간 상한)
