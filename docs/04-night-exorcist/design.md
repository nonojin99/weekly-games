## 0. 한 줄
조선의 밤, 요괴 떼가 사방에서 몰려온다. 조이스틱으로 피해 다니면 무기는 알아서 쏜다. 레벨업마다 3택1로 무기·부적을 키워 **10분을 버티면 동이 튼다.**
다음 밤은 더 어둡고(밤 단계), 퇴마사는 더 강해진다(영구 수련) — 하지만 수련은 상한이 있고 밤은 계속 깊어진다.

**검증된 뼈대** = 뱀파이어 서바이벌류(자동 공격 서바이벌 + 레벨업 3택1 + 영구 메타).
**감성 스킨** = 조선 밤 퇴마 — 부적·목검·방울·염주·횃불·활, 요괴(달걀귀신·구미호·강시·도깨비·물귀신), 보스(5분 두억시니·10분 이무기). 누적이 보이는 화면 = **요괴 도감 + 사당**(해금한 무기·캐릭터가 걸림).

## 1. 데이터 근거
- 1호(방치): 세이브 9명 전원 재방문 — "내 것이 자란다" 작동. 2호(TD, 긴 런·고난도): 재방문 0.43.
- 3호는 **한 런 10분 + 영구 성장**으로 둘의 중간. 런제라 design-principles 원안(0장 3층·2장 황금 곡선·4장 첫 3런·5장 챌린지)이 그대로 적용된다 — 방치형 개정판이 아니라 **원안으로 검증**했다.

## 3. 3층 설계
- **층1 조작 (초)** — 왼손 가상 조이스틱(화면 아무 데나 터치 시작 = 스틱 원점, 데스크톱 WASD/방향키). 공격은 전부 자동. 조작의 전부는 **위치 선정**: 적 틈새로 빠지기, 보석 줍기, 보스 거리 유지. 벌칙 = 접촉 피해(초당). 회피 실력이 곧 생존 시간 — 봇 시뮬의 dodge 0.30/0.55/0.78 이 그 축이다
- **층2 런 내 자원 (분)** — XP 보석 → 레벨업 3택1. 무기 슬롯 4 + 패시브 슬롯 3. 선택 = 빌드(관통 부적 ↔ 근접 목검 ↔ 오라 방울…). 보물상자(보스 드롭) = 무기 진화. 회복은 드문 드롭(인삼)뿐 → 체력이 런을 관통하는 자원
- **층3 메타 (판 사이)** — ① **해금**(달라지는 것): 캐릭터 4종(퇴마사·무녀·포수·떠돌이 중) 시작 무기·특성이 다름, 무기 6→9종, 밤 단계 ② **수련**(강해지는 것, 상한): 공격·체력·회복·이속·획득 5항목, `power(r) = 1 + 1.0·(1 − 0.9^r)` 로 r→∞ 에서 ×2.0 수렴. 재화 = 런에서 모은 **엽전** ③ **스테이지(맵)**: 난이도는 맵마다 고정 (2026-10-03 Howon 결정). 처음 3개 — 달빛 들판 ×1.0 / 안개 늪 ×1.45 / 폐사지 ×1.8 (적 체력 배율, 스폰 동일; 각각 메타 r0·r≈8·r≈18 의 power 와 밴드 안). 앞 맵 클리어 시 다음 맵 해금, 맵마다 요괴 구성·배경이 다름. 추후 맵 추가로 난이도 사다리를 늘린다. sim 의 `challenge(n)` 은 맵 추가 시 배율을 고르는 기준식으로만 쓴다

자문: 메타 0 신규가 밤1 클리어 가능? → SKILLED 봇 가능(10m00s), NORMAL 8분. 풀메타 NOVICE가 밤1을 조작 없이 이기나? → 밤1은 이긴다(10m00s) — 하지만 자기 사다리 밤(밤20)은 못 깬다(4m19s). 긴장은 밤 사다리가 지킨다.

## 4. 수식 (sim 상수 그대로)
```
스폰   s(t) = 1.2 + 0.006·t   (/초, 0→10분 4.8/초)      화면 동시 상한 60
적 체력 h(t) = 10 · 1.0032^t · challenge(night)          (10분 ×6.8)
보스   5분 두억시니 h×40, 10분 이무기 h×120 (광역 무기라 DPS 70% 적용)
DPS    12 · power(r) · 1.2^level,  레벨 n 필요 XP = 12 · 1.18^n
접촉   적 1마리 1.1/초 (최대 8마리 동시), 봇 회피율만큼 감쇄
체력   100 · power(r), 자연회복 0.35/초 · power(r)
power(r)     = 1 + 1.0·(1 − 0.90^r)       (수련 5항목 합산 상한 ×2)
challenge(n) = 1 + 0.975·(1 − 0.86^n)     (밤 단계)
```
### 게이트 A 결과
| 검사 | 결과 |
|---|---|
| 밴드 유지 challenge/power 0.90~1.15 (0~200) | PASS — 최대 편차 1.076 @r=6 |
| 포화 power(200)/power(∞) ≥ 0.98 | PASS — 1.000 |
| 챌린지 공정성: SKILLED 메타0 밤1 클리어 | PASS — 10m00s lvl19 |
| NORMAL 메타0 밤1 7~10분 | PASS — 8m05s |
| 신규 진입: NOVICE 런1 3~6분 | PASS — 4m18s |
| 메타 가치: 풀메타 NOVICE 밤1 클리어 | PASS — 10m00s (r20 9m44s) |
| 긴장 유지: NOVICE r20 밤20 미클리어 | PASS — 4m19s |
| 사다리 공정: SKILLED r20 밤20 클리어 | PASS — 10m00s |

실패했던 모델 2건(기록): 밤 배율을 체력·스폰 양쪽에 걸면 실효 ×3.2라 풀메타도 36초 사망 → 체력에만. 보스전 중 잡몹 DPS 40%면 5분 보스가 사형선고 → 광역 가정(보스 70% + 잡몹 100%).
⚠ 6일차: 이 모델은 "풀접촉" 추상화라 실제 회피율은 맵·적 이속에 좌우된다. `play_events` 의 over 시각 분포로 NOVICE 4분·NORMAL 8분이 실측과 맞는지 보고 HP_G 를 조정한다.

## 5. 첫 3런
- **런 1**: 시작 화면 = 로고 + "움직이기만 하세요. 공격은 알아서." + 버튼 하나. 캐릭터 1(퇴마사, 부적). 사당·수련·도감 전부 숨김. 첫 레벨업(≈20초)에서 3택1 등장 → 층2 학습
- **런 2**: 결과 화면에서 **확정 해금** "목검" (랜덤 아님) + 사당 화면 첫 노출. 닉네임·PIN은 여기서(런1 종료 뒤)
- **런 3**: 캐릭터 2 해금 선택지 2개 제시(무녀 vs 포수) → 빌드 개념
- 수련(엽전) 탭은 런 3 뒤 노출. 밤 2는 밤 1 클리어 시

## 8. 아트·조작 방향
- 탑다운, 캐릭터·요괴는 캔버스 벡터 + 2프레임 보행(스쿼시). 플레이어 24px, 잡몹 18~22px, 보스 64px. 1호 픽셀 페이퍼돌은 안 씀(조합이 없음)
- 들판 = 타일 반복 + 달빛 비네팅 + 반딧불, 시간이 갈수록 어두워지고 안개 → 세계 변화
- 성능: 동시 적 60 + 투사체 ~80 + 보석 ~150. 오브젝트 풀, `ctx` 상태 변경 최소화. 저사양 폰 60fps 목표(390×844)
- 조이스틱: 터치 시작점이 원점(플로팅), 데드존 8px, 최대 반경 48px. 손가락이 화면을 가리지 않게 캐릭터는 화면 중앙보다 약간 위
- 피드백 티어(art-and-ux H): 처치 = 일반 파티클, 보스 피격 = 강타, 레벨업 = 전환(섬광 + 시간 정지)
